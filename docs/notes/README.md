# Notes And Plans

This folder is the single place for project notes, implementation plans, and working markdown documentation.

## What goes here

- Architecture notes
- Implementation plans
- Progress summaries
- Feature-specific references
- Technical decisions

## Naming convention

Use clear uppercase snake-case names for consistency:

- `FEATURE_NAME_PLAN.md`
- `FEATURE_NAME_SUMMARY.md`
- `TOPIC_QUICK_REFERENCE.md`

Examples:

- `AUTH_REFACTOR_PLAN.md`
- `VIDEO_SESSION_SUMMARY.md`
- `PAYMENT_QUICK_REFERENCE.md`
